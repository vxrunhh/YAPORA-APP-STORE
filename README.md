# YAPORA APP STORE

**Discover. Download. Explore.**

An independent Android marketplace for discovering and downloading apps built by independent developers — no account or login required.

---

## 📥 Download

**YAPORA APP STORE** (`com.yapora.appstore`)

- Minimum Android: 8.0+
- Distributed outside Google Play
- No sign-up needed to browse or download

---

## ✨ Features

- **Zero-Barrier Access** — Browse, search, and download apps without creating an account
- **Dynamic Categories** — Tools, Productivity, Social, Games, Music, and more
- **Real-Time Search** — Find apps by name, developer, or package
- **App Details** — Screenshots, version info, file size, release history, and privacy links
- **Streaming Download Manager** — Live progress, download speed, and SHA-256 integrity verification
- **Download Library** — View local download history and quickly re-install
- **Developer Portal** — Google Sign-In for developers to publish apps, track downloads, and manage memberships
- **In-App Notifications** — Real-time updates on approvals and membership status

---

## 🔒 Security Notice

Applications are distributed outside Google Play. Install applications only from developers you trust. All downloads are verified against developer-provided SHA-256 checksums.

---

## 🛠 Requirements

- Android 8.0 (API 26) or higher
- Internet connection
- Permission to install apps from unknown sources (Android will prompt you)

---

## 📱 Install

1. Download the YAPORA APP STORE APK
2. Open the file and allow installation from unknown sources when prompted
3. Launch the app and start exploring

---

## 👨‍💻 For Developers

Developers can join through the in-app Developer Portal using Google Sign-In to submit apps, monitor analytics, and manage releases.
